Location Check-In

EPI District Chakwal · Vaccinator field location

Steps
1) Select Tehsil → UC → your name
2) Enter the Kit Station Name where you will vaccinate today (e.g. H.H Nazia, Bethak Noor Khan)
3) Tap Get My Location and allow location access
4) Tap Submit Location
